# DownloadServer

Серверна частина Network Download Manager.

## Запуск
1. Відкрийте `DownloadServer.csproj` у Visual Studio 2022/2026.
2. Переконайтеся, що встановлено .NET 8 SDK.
3. Запустіть проєкт (F5 або Ctrl+F5).

Сервер слухає TCP-порт 5000. Завантажені файли зберігаються у папці `downloads` поруч із виконуваною програмою.

Клієнт за замовчуванням підключається до `127.0.0.1:5000`. Для роботи на іншому комп'ютері змініть `ServerHost` у `DownloadClient/Program.cs` на IP-адресу сервера та дозвольте TCP-порт 5000 у брандмауері.
